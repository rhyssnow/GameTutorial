 The tutorial level for a 2d top down metroidvania game I am making, it draws heavy inspiration from Hollow Knight and the Dark Souls series, or at least it will; it's not very far in development. The idea for this game has been festering in my mind since Silksong, because though it's a great game, it didn't quite have the magic that hollow knight did. Of course, this game is going to be (if i finish) significantly worse than Silksong, but I thought it would be a fun experience. Uses the pixel engine backend I worked on the first two weeks. Almost done (the tutorial, not the whole thing), just needs a bug fix or two, tutorial messages, some animations, and a main menu. hopefully will be done next week, but maybe two more.

CONTROLS:
WASD for movement
X for attack
Shift for sprint
Space to jump
Arrow keys to look in a direction
You can look in a direction other than the one you are moving in, but your speed will be reduced.

The red bar is health, the green is stamina, and the purple is mana (though no mana systems have been added, so you can ignore the purple bar.

The goal of the game is to live as long as possible and kill as many wolves as you can.

Run the project by finding the most recent release, downloading the ZIP file, opening the release directory, and launching the executable titled: PixelEngine
